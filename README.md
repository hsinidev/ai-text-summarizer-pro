## 📖 About The Project

The **AI Text Summarizer** redefines how users interact with Large Language Models for text processing. Unlike standard tools that act as "black boxes," processing your data on opaque servers, this application acts as a secure **client-side interface**.

It connects directly from your browser to your specified LLM endpoint (Ollama, Cloudflare Workers AI, or OpenAI-compatible APIs). This ensures **zero data latency** and **100% data sovereignty**.

### Key Features

*   **🌌 Cosmic Immersion:** Features a performance-optimized HTML5 Canvas starfield background and glassmorphism UI for a premium user experience.
*   **🔒 BYOK Architecture:** "Bring Your Own Key/Endpoint" means your data never leaves your control.
*   **⚡ SEO Powerhouse:** Built-in rich content, FAQ, and Schema.org markup to dominate search results.
*   **📱 Universal Design:** Fully responsive layout that adapts gracefully from mobile phones to 4K desktop monitors.
*   **🛠 Zero-Build:** No Webpack, no Node_modules. Just pure, optimized web standards.

## 🚀 Usage Guide

1.  **Access the App:** Go to [doodax.com/ai-summarizer](https://doodax.com/ai-summarizer/).
2.  **Configure Endpoint:**
    *   Locate the "LLM Endpoint URL" field.
    *   Enter your API URL (e.g., `https://your-ollama-instance.com/api/generate`).
    *   *Note: Ensure your endpoint allows CORS.*
3.  **Summarize:**
    *   Paste your text.
    *   Adjust length (1-10 sentences).
    *   Click **Summarize Now**.

## 🚀 Quick Start & Installation

### 1. Clone the Repository
```bash
git clone https://github.com/hsinidev/ai-text-summarizer-pro.git
cd ai-text-summarizer-pro
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Launch the Application
